# ⚖️ Calculadora de IMC

## 📝 Descrição do Projeto
Calculadora de **Índice de Massa Corporal (IMC)** em uma única página. O usuário informa o peso (kg) e a altura (m), e o JavaScript calcula o IMC (peso ÷ altura²), exibe o valor com duas casas decimais e mostra a classificação (baixo peso, peso normal, sobrepeso e obesidade graus I, II e III). A página também avisa quando os valores informados são inválidos e esclarece que a tabela é uma referência geral para adultos.

Desenvolvido como parte da disciplina de **Desenvolvimento Front-End Para Web (2026.2)**.
