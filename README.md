# ⚖️ Calculadora de IMC

## 📝 Descrição do Projeto
Calculadora de **Índice de Massa Corporal (IMC)** em uma única página. O usuário informa o peso (kg) e a altura (m), e o JavaScript calcula o IMC (peso ÷ altura²), exibe o valor com duas casas decimais e mostra a classificação (baixo peso, peso normal, sobrepeso e obesidade graus I, II e III). A página também avisa quando os valores informados são inválidos e esclarece que a tabela é uma referência geral para adultos.

Desenvolvido como parte da disciplina de **Desenvolvimento Front-End Para Web (2026.2)**.

## 🚀 Tecnologias Utilizadas
* **Linguagem:** HTML5, CSS3 e JavaScript
* **Ferramentas:** VSCode, Git e GitHub
* **Hospedagem:** GitHub Pages
* **Modelo de IA:** ChatGPT (GPT-6) – apoio na criação inicial do código

## 📊 Resultados e Aprendizados
* Formulário com campos de peso e altura, validação dos dados e resultado exibido na própria página, sem recarregar.
* Classificação do IMC pelas faixas gerais para adultos, com aviso de que não se aplica a menores de 18 anos.
* **Aprendizados:** Aprendi como estruturar uma página HTML, utilizar JavaScript para realizar cálculos, capturar informações dos campos de formulário e apresentar resultados dinamicamente utilizando eventos e condicionais.
